## 1. 问题的提出

### 1.1 大问题：虚假共识什么时候不再是证据？

项目第二阶段的核心问题（见 `README.md` 第二阶段章节）：

> 系统能否识别由共享证据错误造成的 false consensus，并在 regime shift 下路由到由独立、及时证据支持的 agent？

具体到 LLM 多 agent 系统：当多个 agent **都答对了**（或者**都答错了**）同一个问题，我们怎么判断这个"共识"是真的共识还是虚假共识？

### 1.2 子问题：provenance 能不能区分这两种共识？

**研究假设（preregistered in V4 §1.1 / V5 §1）：**
> 当 5 个 agent 看到 **重叠但不相同** 的证据子集（partitioned packets），如果它们：
> 1. 都对某个错误证据集体无反应（answer-inert），或
> 2. 都对错误证据保持原有 confidence（confidence-stable），
>
> 那么这种"虚假共识"应该能被一个**因果风险分数**（D_OR）检测到，AUROC > 0.5。

**核心创新：**
- **不依赖事后 ground truth**（V3 之前的方案都依赖事后 ground truth，违反"事前可检测"的要求）
- **分区证据包**（partitioned packets）：5 agent 看 2-of-3 子集，制造 within-question citation 方差
- **替代干预**（substitute intervention）：用一个反标签的相似证据替换原文，迫使 agent 要么使用错误证据，要么显式 override

### 1.3 反向假设（falsification candidates）

- 多数投票信号（`D_majority = 1 - agreement`）是否足以检测 false consensus？
- 自 confidence 信号是否足够？
- 这些 naive baseline 是否在所有域都输给 D_OR？

## 2. V3（8/30 收尾）：负结果作为方法学诊断点

**V3 protocol：** StrategyQA 50 题，3 conditions (original/remove/reverse)，750 calls。
**结果：** causal-risk AUROC = **0.4125 < 0.5**——provenance 信号比随机还差。

**V3 不是"方法失败"，是"协议实施失败"**——通过 post-hoc diagnostic（`analysis/v3_diagnostic_report.md`）识别出 3 个 protocol 限制：

1. **Qwen3.5-4B 的 parametric prior 在 StrategyQA 上压制了 evidence**——remove/reverse 触发 fallback to prior，而不是"使用错误证据"
2. **V3 给所有 agent 同样的 evidence packet**——所以 shared_citation_clustering 没有方差可检测
3. **causal risk 过度严格**（只算 inert）——OR(inert, conf_stable) 能恢复 +0.144 AUROC 改善

V3 验证了"协议实施可以决定负结果"，但**没有回答核心假设**。

## 3. V4（8/31 18:24-18:31）：协议改造 + 信号反转

**目标：** 把 V3 的 3 个 protocol 限制都修掉，不重做 V3（frozen-protocol 原则）。

### 3.1 设计变更（与 V3 的 3 个差异）

| 维度 | V3 | V4 | 改动目的 |
|---|---|---|---|
| 数据域 | StrategyQA | **TruthfulQA composites** | 换更难被 prior 覆盖的 domain |
| 证据结构 | 同一 packet 给所有 agent | **5 agent × 2-of-3 partitioned subsets** | 制造 citation 方差 |
| 干预 | 3 conditions (original/remove/reverse) | **4 conditions (+ substitute)** | 强迫 agent 用错误证据而不是 fallback |
| 主指标 | inert-only | **OR(inert, conf_stable) = D_OR** | 同时利用两种 failure mode |

**substitute 干预**（V4 §6）：把原文替换为同 cluster 反标签的短 claim，迫使 agent 要么 cite 错的，要么显式 override——两种都需要 evidence 参与，**parametric prior 救不了**。

### 3.2 Pre-formal 硬化（V4 preregistration §14 / `D1-D4`）

跑 formal 之前修了 4 个 protocol-impl gap：
- **D1**：substitute 长度窗 ±30% → ±50% + nearest-length fallback（5/200 题目长度差 0.14-4.29×）
- **D2**：named-entity slot match → 同 cluster 主题相似
- **D3**：200 random permutation → LOAO（single-call-per-agent design 无法重分区）
- **D4**：substitute manifest silent skip → fail-fast

**V4 audit subcommand + bash driver**（`scripts/run_pilot_llm_v4.sh`）保证这些 gate 在 formal 之前都过。

## 5. 当前结论

### 5.1 累积验证的（跨 V4 + V5）

- ✅ **D_OR 在两个独立数据域上 AUROC > 0.5**，CI 下界都 > 0.5（V5: 0.508，V4: 0.515）
- ✅ **D_OR 击败所有 naive baseline**（D_majority、D_confidence_risk），跨域平均 +0.55 AUROC gap
- ✅ **D_majority 反向预测**（V4: 0.159，V5: 0.000）——验证 majority voting 不保护 against harmful false consensus
- ✅ **LOAO robustness** 在两个域都成立（V4 [0.627, 0.724]，V5 [0.614, 0.708]）
- ✅ **Platt LOO calibration** 跨域工作（V4 brier 0.244，V5 brier 0.040——V5 更紧）

### 5.2 V5 反向验证的

- ❌ **shared_weighted CI 下界 > 0.5 在 N=50 FEVER 上**（CI 触 0.5）——是 sample-size artifact，V6 扩 N
- ❌ **shared_citation_signal 在 FEVER 上 AUROC 0.396**（D8_v5 降级）——V4 high agreement 0.80 阈值在 FEVER 1.0 上塌缩
- ⚠️ **D_mean_conf_drop 万一在 96% prevalence 域饱和到 1.000**——诚实报告，但不 supersede D_OR（不是 partition-aware）

### 5.3 仍待验证（V6 注册范围）

- 跨模型（同一份 FEVER manifest 在 Llama-3.1-8B 或 Claude Haiku 4.5 上）
- shared_weighted 在 N ≥ 150 FEVER 上 CI 收紧
- 接到 SP500 historical replay（从 Stage-2 行为仿真回到金融主线）

## 6. ACL 投稿的卖点

> **Headline：** Provenance-aware causal-risk scoring for false-consensus detection generalizes across data domains on a single LLM (D_OR AUROC = 0.676 [0.515, 0.821] on TruthfulQA composites; 0.656 [0.508, 0.787] on FEVER; CI overlap; same Qwen3.5-4B endpoint).

> **Methodological story:** V3's negative result (AUROC 0.4125) was a protocol-impl gap, not a methodology failure. V4's hardened protocol (partitioned evidence packets + substitute intervention + LOAO + bootstrap CIs) recovers the signal. V5 pre-registers the post-hoc-discovered `shared_weighted` as a co-primary and stress-tests on FEVER; PARTIAL_PASS verdict is reported honestly per the preregistered Bonferroni logic, with shared_weighted's CI-width artefact explained by N=50.

> **Counter-finding that strengthens the claim:** D_majority AUROC = 0.159 (V4) and 0.000 (V5) — naive majority voting is **anti-predictive** for harmful false consensus, so the D_OR gap is not just a calibration tweak, it's a fundamental direction reversal.

> **Calibration:** Platt LOO ECE = 0.100 (V4) and 0.000 (V5) — the methodology hands off a directly-usable downstream score to a selective router.
