# Synthetic V1 formal experiment

This report is generated by `python -m sp500_forecastability.synthetic_experiment`. The protocol was frozen in [the preregistration](../docs/synthetic_v1_preregistration.md).

## Protocol snapshot

- Base-seed clusters: 101, 211, 307, 401, 509, 601, 709, 809, 907, 1009.
- Generated independent episodes: 960 before held-out test expansion; 2880 pooled held-out test rows.
- Evaluation: leave-one-corruption-mechanism-out; both clean controls appear in each test fold.
- Frozen threshold: 75th percentile of training-only pre-outcome risks; abstain iff risk is strictly greater.
- Uncertainty: 1000 base-seed-cluster bootstrap resamples; percentile 95% CI.
- Oracle is diagnostic only and is excluded from deployable-method interpretation.

## Interpretation boundary

These are controlled synthetic results. They validate whether the contract and routing signals behave under known interventions; they do not demonstrate S&P 500 predictability, LLM faithfulness, or investment performance.
